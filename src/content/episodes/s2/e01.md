- `pg_locks` 와 `pg_stat_activity` 를 조인해서 누가 누구를 기다리는지 그래프로 그려봤다
- 원인은 배치 잡의 `SELECT … FOR UPDATE` 순서가 API 와 반대였던 것
- **Q&A**: "advisory lock 으로 바꾸면 안 되나요?" → 다음 회차 숙제로

```sql
SELECT blocked.pid, blocking.pid AS blocking_pid, blocked.query
FROM pg_stat_activity blocked
JOIN pg_locks bl ON bl.pid = blocked.pid AND NOT bl.granted
JOIN pg_locks kl ON kl.locktype = bl.locktype AND kl.granted
JOIN pg_stat_activity blocking ON blocking.pid = kl.pid;
```
